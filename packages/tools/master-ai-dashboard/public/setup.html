LOCAL MAC · KEYS · DMG

MASTER AI COMMAND CENTER

Clear setup steps and official URLs for API keys. Target this local Mac for now. After npm run package:mac, refresh Finder and open the new .dmg under release/.

▶ Launch cockpit (index) Pinterest Apps Console Node.js LTS Electron Mac DMG docs

1. Local Mac prerequisites MAC LOCAL

Install Node.js LTS (20.x). Clone or open the repo on this Mac. Skip cloud deploy for now.

  • Download Node.js LTS Required runtime https://nodejs.org/en/download
  • Open repo on GitHub Source + PR https://github.com/Sparkey333/babylon.js

2. Run the Command Center locally MAC LOCAL

From the repo root:

npm install
npm run build:dev
npm run serve -w @tools/master-ai-dashboard
# open http://localhost:1347
  • http://localhost:1347/ Dev cockpit (when serve is running)
  • Vite guide https://vite.dev/guide/

3. Create a Pinterest app (get keys)

Create a Pinterest developer app, then copy App ID and App Secret. Add redirect URI http://localhost:1347/oauth/pinterest/callback. Store secrets in .env.local on this Mac — never commit them.

  • Pinterest Developers home https://developers.pinterest.com/
  • Set up your app (official) Create App ID + App Secret https://developers.pinterest.com/docs/getting-started/set-up-app/
  • Apps console (keys) Copy App ID / Secret here https://developers.pinterest.com/apps/

4. Connect OAuth → boards & pins

Follow Pinterest Authentication. Use board/pin scopes. Run a tiny local proxy on Mac that holds App Secret and exchanges the code for a token. Point the Inspiration pane at that proxy.

  • Authentication docs https://developers.pinterest.com/docs/getting-started/authentication/
  • API v5 reference https://developers.pinterest.com/docs/api/v5/

5. Optional — AI co-pilot keys

For a future AI chat panel, create keys on OpenAI and/or Anthropic. Keep them in Keychain or local .env on this Mac only.

  • OpenAI API keys https://platform.openai.com/api-keys
  • Anthropic API keys https://console.anthropic.com/settings/keys

6. Package & open a fresh Mac DMG MAC LOCAL

On this Mac, run the package script. When it finishes: refresh Finder, then open the new .dmg under packages/tools/master-ai-dashboard/release/. Drag Master AI Command Center into Applications, then launch. 

cd packages/tools/master-ai-dashboard
npm run package:mac
# then: open release/*.dmg
# or double-click the new DMG in Finder after refresh
  • Electron Builder Mac / DMG docs https://www.electron.build/configuration/mac

7. Verify the cockpit

Drag in the 3D viewport to look around. Open Command Center, Inspiration / Pinterest, Debug Bay, and Setup & Keys. Selecting a project should fly the camera to that life-zone station.

  • Babylon.js docs https://doc.babylonjs.com/
  • Babylon Playground https://playground.babylonjs.com/
